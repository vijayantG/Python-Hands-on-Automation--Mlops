Python Data Structures: Cheat Sheet for MLOps
1. Overview
Data structures organize data for efficient storage and retrieval. In Python, they are categorized by Mutability:

Mutable (Changeable): Lists, Dictionaries, Sets.

Immutable (Unchangeable): Tuples.

2. Lists []
Definition: Ordered, mutable, dynamic arrays that hold heterogeneous data (mix of types).

Best for: Storing collections of items to loop through, or creating tables (list of lists).

Pros: Easy to modify, great for nested data.

Cons: Slower for math (use NumPy for speed), uses more memory.
